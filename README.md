# Pemrograman Dasar - Luminous Quest (TLS 2026)

**Nama:** Petra Sean Azriel Christian Sinaga
**Kelompok:** Ruby

## Isi Repository

- `Fase1_Petra_Sean_Azriel_Christian_Sinaga.pdf` — pseudocode untuk Problem 1 (The Last Astronaut) dan flowchart untuk Problem 2 (Alien-In-The-Middle), beserta penjelasan logika masing-masing.
- `TheLastAstronaut.cpp` — implementasi C++ untuk simulasi eliminasi astronot secara melingkar dengan nilai K yang berubah dinamis setelah setiap eliminasi.
- `AlienInTheMiddle.cpp` — implementasi C++ untuk sistem penyandian huruf berdasarkan nilai alfabet huruf sebelumnya.

## Ketentuan Program

Kedua program C++ hanya menggunakan library `iostream` dan seluruh fungsi yang dibutuhkan dibuat secara manual (user-defined function), sesuai ketentuan Fase 2.

## Cara Menjalankan

```bash
g++ -o TheLastAstronaut TheLastAstronaut.cpp
./TheLastAstronaut

g++ -o AlienInTheMiddle AlienInTheMiddle.cpp
./AlienInTheMiddle
```
